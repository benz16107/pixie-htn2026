# Pitch map

Use [the current judging guide](../DEMO/README.md) and its per-track cards. The common opening is:

> Insurance automation becomes dangerous when a missing value looks like a safe value. Pixie keeps the answer as an interval, names the fact that would settle it, and gives the underwriter the source and counterargument before a decision.

For the renter product:

> The same engine can price a transparent renter quote under a different rule set. Every line on the receipt names its source, and cases that need judgment move to the underwriter desk with the original receipt intact.

Spend most of the five minutes on the sponsor named on the card. Show one input, one provider-specific operation, and one visible result. End with the limitation printed on the card.
